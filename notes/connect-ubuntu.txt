password based authentication
-------------------------------
goto this file sudo vi /etc/ssh/sshd_config
enable "PasswordAuthentication" to "yes"

establish connection two servers permently
 we need to copy public key (use ssh-keygen) from server1 to server2
 "ssh-copy-id server2username@<ip>"
 
set password
------------
sudo passwd USERNAME

Restart Service
---------------
Unix/Linux : sudo systemctl restart sshd
ubuntu: sudo service ssh restart

ssh timeout settings
-------------------- 
ClientAliveInterval 600 --> ClientAliveInterval is set to 600 seconds (60 minutes)
ClientAliveCountMax 6 --> the server will send a keep-alive message every 10 minutes
